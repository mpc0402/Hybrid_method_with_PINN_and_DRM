I attempted to solve p-Stokes problem under user-defined conditions by neural network-based numerical method for PDEs with a hybrid loss function combining PINN and DRM losses.

Two code files are provided: one using the Adam optimizer and the other using the SOAP optimizer.
All other conditions are kept the same in both code files.

Both code files include the corresponding numerical results.
